# vyla/sdk
VylaSDK is a JavaScript base version of [Vyla](https://vyla.mintlify.app/)'s stream & scrape API, allowing developers to access content providers directly without using a REST API. This gives you the power and updates of Vyla without the headaches of API keys and server reliability.

## Installing
To start, install VylaSDK through npm or pnpm:

```bash
# npm
npm install @vyla-entertainment/sdk

# pnpm
pnpm install @vyla-entertainment/sdk
```

View the full documentation at https://docs.vyla.cc/sdk
